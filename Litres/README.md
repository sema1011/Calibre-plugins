# Litres

Litres - это Python-пакет, предоставляющий источник метаданных для Calibre, получая информацию из LitRes (русской библиотеки книг).

## Описание

Этот плагин позволяет Calibre автоматически получать подробную метаданные о книгах через API LitRes.

## Установка

1. Скачайте этот архив ZIP (`Litres.zip`) и распакуйте его.
2. В Calibre: Настройки → Плагины → Загрузить плагин из файла
3. Выберите распаканный файл `__init__.py` как источник плагина
4. Перезапустите Calibre
5. Включите источник LitRes в Настройках → Источники метаданных

## Использование

Пакет содержит:
- `litres/__init__`: Основной модуль с логикой загрузки метаданных
- `litres/Litres.zip`: Пакет плагина (распакуйте для установки)
